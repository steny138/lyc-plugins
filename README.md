# lyc-plugins

A small [Claude Code](https://claude.com/claude-code) plugin marketplace of **mods** — plugins whose hooks draw live UI (panes, buttons) inside the Claude Code terminal.

| Plugin | What it does |
|---|---|
| [`sudoku`](plugins/sudoku) | Play Sudoku in a side pane: unique-solution puzzles generated on the fly, three difficulty levels, conflict highlighting. |
| [`tetris`](plugins/tetris) | 俄羅斯方塊：單機漸進玩法、下一塊預覽、手動暫停，移植自 samtay/tetris。 |
| [`sudoku-online`](plugins/sudoku-online) | 區網數獨競速：房主一鍵開局，同一道題比誰先完成。 |

Sudoku tested with Claude Code 2.1.287; Tetris developed against 2.1.288.

## Install

```sh
claude plugin marketplace add steny138/lyc-plugins
claude plugin install sudoku@lyc-plugins
```

## sudoku

Type `/sudoku` to open the pane; run it again to close it. The board is kept for the rest of the session, so closing and reopening the pane continues the same game.

- Click an empty cell to select it, then press a number on the keypad.
- Duplicates in the same row, column or box are highlighted in red.
- When every cell is filled with no conflicts, the pane shows **完成！** (Done!).

| Key | Action |
|---|---|
| `1`–`9` | Fill the selected cell |
| `x` | Clear the selected cell |
| `e` / `m` / `h` | New easy / medium / hard game (44 / 35 / 26 clues) |

Hotkeys work while the pane has focus (click it, or press `ctrl+x tab`).

Puzzles are generated by filling a random complete grid and then removing cells one at a time, keeping only removals that leave exactly one solution. Every puzzle has a unique solution, and even the hardest level is generated in well under a second.

## tetris

安裝 `claude plugin install tetris@lyc-plugins`，輸入 `/tetris` 開啟或關閉面板。
點棋盤或按 `ctrl+x tab` 切換焦點後，使用 WASD 移動／旋轉、F 落底、P 暫停／繼續、R 重新開始。

關閉或切走面板仍會下落，請先手動暫停。落底後下一次重力才固定；此期間暫停與移動不可用。暫停時重新開始仍保持暫停。
詳細規則、尺寸需求與本機載入方式見 [tetris README](plugins/tetris/README.md)。

## sudoku-online

安裝 `claude plugin install sudoku-online@lyc-plugins`。同一個區網的人一起比賽解同一道數獨。

1. 房主輸入 `/sudoku-online host`：在自己電腦上啟動共同服務，面板列出分享位址。
2. 其他人輸入 `/sudoku-online join <分享位址>`，輸入暱稱加入，按「準備」。
3. 所有人都準備好後，房主選難度開局，倒數 5 秒後公開同一道題。
4. 填完且沒有衝突就自動提交；共同服務驗證答案，依收到的順序排名次並顯示用時。
5. 房主可以「結束本局」（沒填完的人列為未完成），再按「下一局」回到大廳。

| Key | Action |
|---|---|
| `r` | 準備／取消準備 |
| `e` / `m` / `h` | 房主開局：簡單／中等／困難 |
| `1`–`9` | 在選取的格子填數字 |
| `x` | 清除選取的格子 |
| `q` | 房主結束本局 |
| `n` | 房主開始下一局 |

- 房主電腦需要 Node：共同服務以 `node` 執行 TypeScript（已在 Node 22.19 測試），佔用 47900 埠。
- 共同服務跟著房主的面板：房主關閉面板或重新載入外掛，共同服務就停止，本局隨之中止。
- 提交時連不上共同服務，面板會標示「尚未取得共同服務確認」，恢復連線後自動重送。

## Development

Each plugin lives in `plugins/<name>/` with its hooks module in `hooks/` and tests next to it.

```sh
claude plugin validate plugins/sudoku   # manifest, hooks and types contract
claude plugin test plugins/sudoku       # run the *.test.ts files against the engine
claude plugin validate .                # the marketplace manifest
```
