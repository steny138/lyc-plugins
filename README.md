# lyc-plugins

A small [Claude Code](https://claude.com/claude-code) plugin marketplace of **mods** — plugins whose hooks draw live UI (panes, buttons) inside the Claude Code terminal.

| Plugin | What it does |
|---|---|
| [`sudoku`](plugins/sudoku) | Play Sudoku in a side pane: unique-solution puzzles generated on the fly, three difficulty levels, conflict highlighting. |
| [`tetris`](plugins/tetris) | Play Tetris in a pane: single-player with increasing speed, next-piece preview and manual pause, ported from samtay/tetris. |
| [`sudoku-online`](plugins/sudoku-online) | Race on the same Sudoku over your LAN: the host starts a game in one step, and whoever finishes first wins. |

Sudoku tested with Claude Code 2.1.287; Tetris and sudoku-online developed against 2.1.288.

## Install

```sh
claude plugin marketplace add steny138/lyc-plugins
claude plugin install sudoku@lyc-plugins
claude plugin install tetris@lyc-plugins
claude plugin install sudoku-online@lyc-plugins
```

Install only the plugins you want.

## sudoku

Type `/sudoku` to open the pane; run it again to close it. The board is kept for the rest of the session, so closing and reopening the pane continues the same game.

- Click an empty cell to select it, then press a number on the keypad.
- Duplicates in the same row, column or box are highlighted in red.
- When every cell is filled with no conflicts, the pane shows **完成！** (Done!).

| Key | Action |
|---|---|
| `1`–`9` | Fill the selected cell |
| `x` | Clear the selected cell |
| `e` / `m` / `h` | New easy / medium / hard game (44 / 35 / 26 clues) |

Hotkeys work while the pane has focus (click it, or press `ctrl+x tab`).

Puzzles are generated by filling a random complete grid and then removing cells one at a time, keeping only removals that leave exactly one solution. Every puzzle has a unique solution, and even the hardest level is generated in well under a second.

## tetris

Type `/tetris` to open the pane; run it again to close it.

| Key | Action |
|---|---|
| `a` / `d` | Move left / right |
| `w` | Rotate counter-clockwise |
| `s` | Move down one row |
| `f` | Hard drop (locks on the next gravity tick) |
| `p` | Pause / resume |
| `r` | Restart |

Hotkeys work while the pane has focus (click it, or press `ctrl+x tab`).

- Pieces keep falling while the pane is closed or in the background, so pause first.
- After a hard drop, moving, rotating, dropping again and pausing are unavailable until the piece locks; `r` still restarts.
- Restarting while paused stays paused.

See the [tetris README](plugins/tetris/README.md) for full rules, size requirements and how to load it locally.

## sudoku-online

Everyone on the same LAN races to solve the same puzzle.

1. The host types `/sudoku-online host`. This starts the shared service on the host's machine, and the pane lists the addresses to share.
2. Everyone else types `/sudoku-online join <shared address>`, enters a nickname, and presses **準備** (Ready).
3. Once everyone is ready, the host picks a difficulty to start. After a 5-second countdown, the same puzzle is revealed to all players.
4. A board that is filled with no conflicts is submitted automatically. The shared service checks the answer, ranks players in the order it receives correct boards, and shows each player's time.
5. The host can press **結束本局** (End round), which lists players who didn't finish as unfinished, then **下一局** (Next round) to return to the lobby.

| Key | Action |
|---|---|
| `r` | Ready / cancel ready |
| `e` / `m` / `h` | Host starts an easy / medium / hard game |
| `1`–`9` | Fill the selected cell |
| `x` | Clear the selected cell |
| `q` | Host ends the round |
| `n` | Host starts the next round |

Hotkeys work while the pane has focus (click it, or press `ctrl+x tab`).

- The host's machine needs Node: the shared service runs TypeScript with `node` (tested on Node 22.19) and listens on port 47900.
- The shared service lives with the host's pane: closing the pane or reloading the plugin stops it and ends the round.
- If the shared service can't be reached at submission, the pane shows **已完成，尚未取得共同服務確認** (Finished, not yet confirmed by the shared service) and resubmits automatically once the connection is back.

## Development

Each plugin lives in `plugins/<name>/` with its hooks module in `hooks/` and tests next to it.

```sh
claude plugin validate plugins/<name>   # manifest, hooks and types contract
claude plugin test plugins/<name>       # run the *.test.ts files against the engine
claude plugin validate .                # the marketplace manifest
```
